# Flowscanner Testing Guide (Quiklook 3)

## Overview
This guide documents standard procedures for testing Air Operated Valves (AOV) using the Quiklook 3 Flowscanner. It's written for field technicians and is designed to be concise, offline-friendly, and easy to access from the PlantPouch app.

## Goals
- Provide a clear, repeatable step-by-step test procedure
- Explain how to interpret common Flowscanner outputs
- Offer a compact troubleshooting decision tree for on-site fixes

## Safety and Prep
- Follow site safety procedures and lockout/tagout before testing.
- Required equipment: Quiklook 3 Flowscanner, calibration kit, appropriate fittings, PPE.
- Verify instrument battery or power and clean connectors before starting.

## Quick Start (one-click checklist)
1. Connect Flowscanner to the test valve per manufacturer cable layout.
2. Power on the Flowscanner and load the correct test profile for AOV testing.
3. Run the pre-checks (connection, zeroing/calibration, leak test).
4. Execute the test procedure and record the resulting logs.

## Step-by-step Test Procedure (high level)
1. Identify the valve and record tag/serial number in PlantPouch.
2. Install the Flowscanner connections and confirm a good seal.
3. Configure the Quiklook test: select flow units, sample rate, and test length.
4. Start the test and monitor live readings for obvious errors.
5. Save the test file and export the log to the PlantPouch equipment entry.

## Common Failures and Short Actions
- Device not powering: check batteries/charger and power LED.
- No data / connection errors: re-seat cable, check connector pins, restart device.
- Unexpected zero or offset: re-zero instrument and rerun calibration.
